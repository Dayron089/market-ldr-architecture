# Example 5 — Конкурентный ресёрч RU рынка

> Дима спросил про русскоязычную аудиторию (TikTok + YT Shorts). Бот через `competitor-analysis-report` skill сделал ресёрч, нашёл российских конкурентов, сравнил позиционирование, выдал killer-аргументы под лендинг.
>
> Скрин этой сессии → [`screenshots/03-ru-competitor-research.jpg`](../screenshots/03-ru-competitor-research.jpg)

---

## Запрос Димы

> сделай качественный ресёрч для русскоязычной аудитории. что есть на рынке РФ, какое позиционирование, что у нас сильнее. англоязычную не убирай — потом пригодится.

## Что бот сделал

1. Запустил `competitor-analysis-report` skill
2. Web search по российским AI companion сервисам
3. Сравнил по матрице: фичи, цены, позиционирование, payment methods
4. Нашёл killer-аргументы для FORELDR
5. Сохранил в `memory/competitor-research-ru-2026-03.md`

## Зачем это работает

Бот не выдаёт это с нуля каждый раз. После этой сессии:
- В `MEMORY.md` появилась строка "Lovix.ai = главный RU конкурент, $49 за память"
- В `STRATEGY.md` (с одобрения Димы) добавилась RU-секция
- Все будущие RU сценарии генерятся с этим контекстом сразу — не нужно переобъяснять

Это и есть **knowledge compounds**. Через месяц бот знает RU рынок не хуже чем основной EN.
