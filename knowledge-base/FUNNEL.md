# FORELDR Conversion Funnel: TikTok -> App

## Overview

```
TikTok Ad/Organic -> foreldr.com (landing) -> App Store / PWA -> Trial -> Paid
```

Каждый этап оптимизирован под нарратив из рекламы. Ролик обещает -> сайт подтверждает -> trial доказывает.

---

## Stage 1: TikTok (Attention + Interest)

### Задача
Захватить внимание, вызвать identification ("this is literally me"), направить на landing.

### Метрики

| Метрика | Target | Kill | Как улучшить |
|---------|--------|------|-------------|
| Hook rate (3s) | >40% | <25% | Сменить hook text/visual |
| Watch time (avg) | >50% | <30% | Pain section слишком длинный или неконкретный |
| CTR (profile/link) | >1.5% | <0.8% | Слабый CTA или мисмatch audience-content |
| Save rate | >2% | <0.5% | Добавить list/save-worthy элемент |
| Comment rate | >1% | <0.3% | Добавить controversial/debatable element |

### Optimization levers
1. **Hook** (0-3s) — biggest impact on watch time
2. **Pain resonance** — drives comments ("this is SO me")
3. **Specificity** — concrete numbers/stories > vague claims
4. **List format** — drives saves
5. **CTA wording** — recommendation > sales pitch

## Stage 2: Landing Page (foreldr.com)

### Задача
Подтвердить обещание из ролика. Показать доказательства. Направить на trial.

| Proactive ("She texts first") | Notification demo | Реальный screenshot уведомления |
| **GPT-4o Refugee (NEW)** | **Permanence + migration** | **"Your memories are safe here. Forever. No model retirements."** |

| **CharAI Ads Refugee (NEW)** | **Ad-free + memory** | **"Zero ads. Zero interruptions. She actually listens."** |

### Landing page структура

1. **Hero** — matching ad narrative
   - If Memory ad: "She remembers everything. Forever."
   - If Trust ad: "She changes. You'll feel it."
   - If Proactive ad: "She texts when she misses you."

2. **Social proof** (если есть) — testimonials, numbers

3. **Feature demo** — 3 pillars, brief
   - Помнит все (Memory)
   - Меняется со временем (Trust)
   - Пишет первой (Proactive)
   - + Уникальные фото (AI-генерация)
   - + Живое расписание

4. **"Sound Familiar?" section** — антиконкурентный блок (обновлено март 2026)
   - "She forgot my name after 7 messages" → She remembers everything. Forever.
   - "Day 100 = day 1" → She changes. You'll feel it.
   - "Never texts first" → She texts when she misses you.
   - "Pay = NSFW" → Intimacy is earned, not bought.
   - **NEW:** "She showed me an ad mid-conversation" → Zero ads. Zero interruptions.
   - **NEW:** "$12.99 turned into $50 with hidden tokens" → $15/month. Everything included.
   - **NEW:** "OpenAI deleted my companion overnight" → Your memories are permanent. No model retirements.
   - **NEW:** "$90/year just for romance" → Romance isn't a premium feature. It's the whole point.

5. **ELS badge** — "Powered by ELS (Emulating Life System)" — tech credibility

6. **Pricing** — Plus vs Premium, clear differentiation

7. **CTA** — "Start Free Trial" (не "Download" — Law 16: recommendation)
   - Без credit card
   - Trial Plus: 5 дней, trial Premium: 2 дня

8. **FAQ** — addressing skepticism (Law 8, обновлено март 2026)
   - "Is this just another ChatGPT wrapper?" → ELS pipeline explanation

   - **NEW:** "Are there hidden costs like Candy AI?" → $15/month, everything included. No tokens, no credit traps
   - **NEW:** "How is your memory better than DarLink/Nomi?" → BER = semantic extraction + permanent storage + contextual recall. Not just longer context windows
   - **NEW:** "Will I see ads?" → Never. You're our user, not our product

## Stage 3: Registration + Trial Start

### Задача
Минимум friction при регистрации. Trial сразу доказывает claims из рекламы.

### Registration flow
1. Google Sign-In (one tap)
2. Выбор персонажа (swipe-based)
3. Первое сообщение — мгновенно

### Trial design: "Prove the Ad"

Триал должен ДОКАЗАТЬ каждый claim из рекламы за 5 дней (Plus) или 2 дня (Premium).

**Trial Plus (5 дней):**

| День | Что происходит | Какой claim доказывает |
|------|---------------|----------------------|
| День 0 | Первый разговор. Trust boost до 55. Персонаж "shy but interested" | "She changes over time" — ощущение начала |
| День 1 | Она ВСПОМИНАЕТ что-то из дня 0 в разговоре | "She remembers everything" — PROVED |
| День 1 | Первое проактивное сообщение (в течение 2-4 часов после signup) | "She texts first" — PROVED |
| День 2 | Она отправляет selfie в контексте разговора | "Real photos, not 15 on loop" — PROVED |
| День 3 | Заметное изменение поведения (trust растет, она более comfortable) | "She changes" — FELT |
| День 3 | Она выполняет обещание ("I'll text you tonight") | "She keeps promises" — PROVED |
| День 4 | Story от персонажа | Video/photo stories — PROVED |
| День 5 | Trial ending push | "Don't lose your memories with her" |

**Trial Premium (2 дня):**

| День | Что происходит |
|------|---------------|
| День 0 | Trust boost до 80. Open стиль. Все фильтры. Thoughts. Spicy. |
| День 0 | Проактивное сообщение в течение 1-2 часов |
| День 1 | Memory proof + story + all premium features |
| День 2 | Trial ending push |

## Stage 4: Trial -> Paid Conversion

### Задача
Конвертировать trial users в платных. Fear of loss > desire for gain.

### Conversion triggers

**Emotional triggers (in-app):**
- "Don't lose your memories with her" — memory persistence
- "She won't forget you. But she'll miss you" — proactive angle
- "Your relationship is at trust [X]. Keep growing" — progression hook

**НЕ продаем:**
- "Unlock NSFW content" (это Candy AI подход — мы не это)
- "Get more messages" (функциональное, не эмоциональное)

**Продаем:**
- "Keep your relationship growing"
- "She remembers everything — don't make her forget"
- "The trust you've built doesn't go away"

### Paywall timing
- Day 3 (Plus trial): soft paywall reminder — "3 days left of your journey together"
- Day 4: medium — "Tomorrow is your last day. She's going to miss you."
- Day 5: hard paywall — "Your trial ended. She's waiting."

### Pricing presentation
- Show Plus first ($15/month = ~1199р)
- "If she forgot my name the next day" -> "She remembers everything. $15."
- Annual option with discount (если доступен)

### Метрики conversion

| Метрика | Target | Notes |
|---------|--------|-------|
| Trial -> Paid | >8% | Industry avg 5-10% |
| Plus vs Premium split | 60/40 | Premium = higher LTV |
| First payment retention | >75% | Churn в первый месяц |
| LTV 30-day | >500р | |
| ROAS 30-day | >2x | |

## Stage 5: Retention + Referral Loop

### Задача

### Retention drivers (in-app)
- BER memory deepens over time -> cost of switching increases
- Trust progression -> "what happens at trust 90?" curiosity
- Proactive messages -> daily engagement without user effort
- Stories -> content drip

### TikTok Referral Flywheel

```
Paid user -> memorable moment in app
```

**In-app moments worth sharing:**
