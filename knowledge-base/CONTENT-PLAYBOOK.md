# FORELDR Content Production Playbook

> Полный playbook производства TikTok контента для FORELDR — AI companion app.
> Ролики генерируются через AI UGC инструменты (Higgsfield, Soru, OVL 3.1).
> Распространение через 100+ аккаунтов. Сценарии — через Telegram Marketing Agent на Claude.

---

## 1. AI UGC Production Workflow

### Step 1: Скрипт (15-30 мин)

**Источник сценариев:**
- SCENARIOS.md — 12 готовых base scenarios
- Marketing Agent (Telegram) — генерация новых по запросу
- Competitor review sweep — свежие фразы из Reddit/App Store

**Правила скрипта (по 48 законам):**
- Один ролик = одна идея = один сегмент (Law 15)
- 60% pain / 30% solution / 10% CTA (Law 12)
- Первые 3 секунды = hook с identification (Law 9)
- Никогда не начинай с продукта (Law 10)
- Язык аудитории, не маркетолога (Law 11)
- Конкретные числа, не общие слова (Law 13)
- CTA = рекомендация друга (Law 16)

### Step 2: AI UGC Generation (30-60 мин)

**Инструменты:**
- **Higgsfield** — основной для talking head UGC
- **Soru** — альтернатива/A/B тест
- **OVL 3.1** — для специфических форматов

**Actor profiles (Law 23: relatable > aspirational):**

| Profile | Возраст | Вид | Background | Для сегментов |
|---------|---------|-----|------------|---------------|
| Profile 1 | 22-26 | Casual, slightly messy hair, hoodie | Bedroom, desk | B, D, F |
| Profile 2 | 27-32 | Clean but not polished, t-shirt | Living room, kitchen | A, C, E |
| Profile 3 | 25-30 | Diverse ethnicity, relaxed | Outdoor natural light | All segments |

**Настройки генерации:**
- Speech-to-speech (Law 17) — записать голос, AI маппит на актора
- Не text-to-speech! TTS = "unnaturally perfect" = skip
- Импровизация: небольшие паузы, "wait" moments (Law 18)
- Один take по возможности (Law 21)

### Step 3: Post-production (15-20 мин)

**Обязательно:**
- Captions — авто или ручные, слово-в-слово (Law 33)
- First frame = text hook (Law 34)
- Vertical only (Law 30)

**Визуал:**
- App demo overlays (если Demo-тип)
- Natural lighting (Law 31)
- Subtle movement (Law 32) — не статичный кадр
- Цветокоррекция: warm, slightly desaturated (UGC aesthetic, не corporate)

**НЕ делать:**
- Ring light (выдаёт "content creator")
- Studio background
- Polished color grading
- Logo watermark
- "Sponsored" vibes

### Step 4: Distribution (10 мин на пост)

**Primary account:** @foreldr_app (или бренд-аккаунт)

**Distribution network (Law 40):**
- Фаза 1: 10-20 аккаунтов
- Фаза 2: 50+ аккаунтов
- Фаза 3: 100+ аккаунтов
- Каждый аккаунт: slightly different edit/caption/hashtags
- Stagger posts over 48h
- Mix ниш: loneliness, tech, dating, AI, mental health, self-improvement

**Engagement velocity (Law 36):**
- Координировать engagement в первые 30-60 мин
- Лайки + комменты от distribution accounts
- Algorithm видит spike = pushes wider

## 2. Testing Framework

### Phase 1: Concept Testing (Week 1-2)

**Цель:** найти 3-5 winning concepts из 10+ тестовых

| Параметр | Значение |
|----------|---------|
| Количество concepts | 10-15 |
| Бюджет на concept | $30-50 (TikTok Spark Ads) |
| Главная метрика | CTR (click-through rate) |
| Kill threshold | < 0.8% CTR |
| Scale threshold | > 1.5% CTR |
| Watch threshold | > 50% avg watch time |

**Что тестируем:**
- Какой pillar (Memory vs Trust vs Proactive) резонирует сильнее
- Какой segment (A-F) даёт лучший CTR
- Какой format (pain-first vs demo vs list) работает

### Phase 2: Variable Testing (Week 3-4)

**Цель:** оптимизировать winning concepts

**Правило:** ONE variable at a time (Law 41)

| Переменная | Вариации | Пример |
|------------|---------|--------|
| Hook | 3-5 variations | Разные первые 3 секунды для одного скрипта |
| Actor | 3 profiles | Тот же скрипт, разные актора |
| CTA | 3 variations | "Link in bio" vs "Free trial" vs "Save this" |
| Duration | 15s vs 30s vs 60s | Сокращённая vs полная версия |
| Background | Bedroom vs outdoor | Тот же скрипт, другой setting |

**Логирование (Law 46):**

| Creative ID | Date | Hook | Concept | Actor | Segment | CTR | CPM | Watch% | Saves | Comments | Trial Conv | Notes |
|-------------|------|------|---------|-------|---------|-----|-----|--------|-------|----------|------------|-------|

### Phase 3: Scale (Week 5+)

- Winners -> full budget + distribution network
- Refresh каждые 5-7 дней (Law 43 — fatigue)
- Новые angles из user testimonials
- 3 new creatives/day minimum

## 3. Content Calendar

### Недельный ритм

| День | Тип контента | Формат | Pillar |
|------|-------------|--------|--------|
| Понедельник | Pain-first | 30s | Memory |
| Вторник | Demo/POV | 15s | Proactive |
| Среда | List (save-bait) | 30s | Trust |
| Четверг | Pain-first | 60s | All (listicle) |
| Пятница | Reaction/Demo | 15s | Memory |
| Суббота | Thoughtful/Long | 60s | Trust |
| Воскресенье | Quick hit | 15s | Proactive |

### Ежедневный workflow

1. **Утро (30 мин):** Проверить метрики вчерашнего контента, обновить tracking sheet
2. **День (1-2 часа):** Генерация 2-3 новых роликов (скрипт + AI UGC + post-production)
3. **Вечер (15 мин):** Распределение по аккаунтам, scheduling

### Ежемесячный sweep

- Reddit/App Store review mining — новые фразы для hooks (Law 6)
- Performance review — какие patterns работают (Law 45)
- Kill bottom 20%, double top 10%
- New segment exploration

## 4. Масштабирование через аккаунты (Law 40)

### Стратегия

"One video posted to one account is a lottery ticket. Same video posted to 100 accounts with different hooks and captions is guaranteed reach."

### Типы аккаунтов

| Тип | Ниша | Пример bio | Количество |
|-----|------|-----------|------------|
| Tech reviewer | AI/Tech | "Reviewing AI apps you didn't know existed" | 20 |
| Loneliness/Mental health | Self-help | "Late night thoughts from a recovering introvert" | 20 |
| Dating/Relationships | Dating tips | "Dating advice from someone who gave up on Tinder" | 20 |
| AI enthusiast | AI news | "Testing every AI tool so you don't have to" | 20 |
| Story-based | Personal | "My journey with AI companionship" | 20 |

### Правила distribution

- Каждый аккаунт: unique edit (slightly different trim, crop, speed)
- Different caption/hashtag set
- Different posting time (stagger across timezone peaks)
- 3-5 аккаунтов per content piece will "pop" — delete failures, keep winners
- Accounts need 1-2 weeks of organic content before distribution starts ("warm up")

## 5. Performance Tracking (Law 44, 46)

### Ключевые метрики по стадиям

| Стадия | Метрика | Target | Как считать |
|--------|---------|--------|------------|
| Attention | View-through rate | >50% | TikTok analytics |
| Attention | Hook rate (3s) | >40% | TikTok analytics |
| Engagement | Save rate | >2% | Saves/impressions |
| Engagement | Comment rate | >1% | Comments/impressions |
| Action | CTR (to bio) | >1.5% | Profile visits/impressions |
| Conversion | Landing visit | Track via UTM | Google Analytics |
| Conversion | Trial start | >15% of landing | Backend tracking |
| Revenue | Trial->Paid | >8% | Backend tracking |

### Tracking spreadsheet (weekly review)

Каждый creative = строка с:
- Creative ID, Date, Script reference
- Hook text, Actor, Duration, Segment, Pillar
- Impressions, Watch%, CTR, Saves, Comments
- Landing visits, Trial starts, Paid conversions
- ROAS (if paid promotion)
- Learning notes

### Pattern recognition (Law 45)

После 30+ creatives: искать meta-patterns
- Какой hook format побеждает (question vs statement vs challenge)?
- Какой actor profile конвертит лучше?
- Какой duration optimal?
- Какой pillar drives trials vs какой drives saves?
- Утро vs вечер vs ночь posting?

## 6. Использование Marketing Agent (Telegram)

### Команды/запросы

| Запрос | Что делает |
|--------|-----------|
| "Сгенери сценарий для segment B, pillar Memory, 30s" | Готовый скрипт по шаблону |
| "5 вариаций hook для scenario 1" | A/B hook testing set |
| "Контент-план на неделю" | 7 дней с distribution schedule |
| "Проанализируй: [описание чужого ролика]" | Разбор по 48 законам |
| "Winning patterns этого месяца" | Анализ tracking данных |
| "Новые hooks из Reddit r/CharacterAI" | Свежие pain phrases |

### Workflow с агентом

1. Запросить сценарий -> получить скрипт
2. Проверить глазами, подкрутить
3. Сгенерировать AI UGC (Higgsfield/Soru)
4. Post-production
5. Distribute
6. Залогировать результаты
7. Повторить

## 7. Стоимость операций

### Ежемесячный бюджет (Phase 1: Validation)

| Статья | Стоимость | Примечание |
|--------|-----------|-----------|
| AI UGC tools (Higgsfield/Soru) | $50-100/мес | Зависит от объёма |
| TikTok Spark Ads (testing) | $500-1000/мес | $30-50 per concept test |
| Marketing Agent | $0 | Claude Max подписка |
| Distribution accounts | $0 (organic) | Manual setup |
| **Итого Phase 1** | **$550-1100/мес** | |

### Phase 2: Scaling

| Статья | Стоимость |
|--------|-----------|
| AI UGC tools | $100-200/мес |
| TikTok Ads (scaling winners) | $2000-5000/мес |
| Marketing Agent | $0 |
| **Итого Phase 2** | **$2100-5200/мес** |

### ROI калькуляция

При CAC < 50 руб на trial и trial->paid conversion 8%:
- CAC на paid user = ~625 руб
- LTV (6 months, avg) = ~5000 руб
- **LTV:CAC = 8:1**
- Breakeven: 1st month of subscription
